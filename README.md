# Simple Hospital Management System (C++)

## 🎯 Purpose:

The main goal of this project is to apply **linked list concepts** in C++ by simulating a simple hospital system.

## 🏥 Description:

This is a simple hospital management system project written in C++ to practice **Data Structures**, specifically **Singly Linked List**.

The system allows basic operations like adding, deleting, searching, retrieving, and updating patient records.

## 💡 Notes:

- This project is for **learning purposes only**.
- It is designed to demonstrate how linked lists can manage dynamic records in memory.
- The program is console-based and does **NOT** include file handling (data will be lost when the program exits).

## 👨‍💻 Tech Stack:

- Language: **C++**
- Concept: **Singly Linked List**

## 🚀 Features:

- ✅ Add new patient
- 🗑️ Delete a patient by ID
- 🔍 Search for a patient by ID
- 📋 Retrieve full patient info by ID
- ✏️ Update patient info (name, age, disease)

## ⚙️ How to Run:

1. Compile the project using g++:
   ```bash
   g++ main.cpp -o hospitalSystem
   ```
   ./hospitalSystem
